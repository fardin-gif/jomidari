# 🏰 ধনী হবার মজার খেলা (jomidar.fun)

বাংলা অনলাইন বোর্ড গেম — স্ট্যাটিক সাইট + Firebase (Anonymous Auth + Firestore)। কোনো বিল্ড স্টেপ নেই।

## ফাইল
- `index.html` — একমাত্র পাতা; `css/style.css` — থিম; `js/*.js` — ইঞ্জিন, কম্পিউটার-বুদ্ধি, অবতার, সাউন্ড, বোর্ড, নেট, পর্দা
- `firebase-config.js` — **এখানে আপনার Firebase কনফিগ বসান**
- `firestore.rules` — Firestore নিরাপত্তা নিয়ম
- `vercel.json` / `netlify.toml` / `.htaccess` / `firebase.json` — `/r/ABCD` লিংকের রিরাইট

## Firebase সেটআপ (একবারই)
1. console.firebase.google.com → **Add project** (নাম: jomidar; Analytics বন্ধ রাখতে পারেন)।
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable**।
3. **Build → Firestore Database → Create database** → Production mode → লোকেশন (asia-south1 বা কাছের)।
4. Firestore → **Rules** ট্যাবে `firestore.rules`-এর লেখা পেস্ট করে **Publish**।
5. Project settings (⚙️) → Your apps → **</> Web** → app নিবন্ধন → দেখানো `firebaseConfig`-এর মানগুলো `firebase-config.js`-এ বসান।
6. Authentication → Settings → **Authorized domains**-এ যোগ করুন: `localhost`, আপনার `xxx.vercel.app`, পরে `jomidar.fun` ও `www.jomidar.fun`।

## Vercel-এ প্রকাশ
- GitHub-এ এই ফোল্ডার পুশ করে Vercel-এ Import (Framework: Other, Build command ফাঁকা, Output ফাঁকা) — অথবা `vercel` CLI।
- ডিপ্লয়ের পর `xxx.vercel.app` ডোমেইন Firebase Authorized domains-এ যোগ করতে ভুলবেন না।

## পরে jomidar.fun (Hostinger)
- **সহজ পথ:** Vercel-এ Settings → Domains → `jomidar.fun` যোগ করুন; Hostinger DNS-এ Vercel-এর দেওয়া A/CNAME রেকর্ড বসান।
- **Hostinger হোস্টিংয়ে ফাইল তুললে:** `index.html, css/, js/, firebase-config.js, favicon.svg, .htaccess` `public_html`-এ আপলোড করুন। ওয়েবসাইট HTTPS-এ চালান।
- যেভাবেই হোক `jomidar.fun` Firebase Authorized domains-এ থাকতে হবে।

## লোকালি চালানো
`python3 -m http.server 8000` → http://localhost:8000 (ফাইল সরাসরি double-click করলে চলবে না, কারণ পাথ `/js/...`)।

- প্রথম ভিজিটে স্তর প্রশ্ন (প্রথমবার ক্রেতা / উদ্যোক্তা / জমিদার); প্রথমবার ক্রেতার জন্য প্রতি ধাপে পরামর্শ + "কেন?" + বাটন জ্বলে ওঠা
- কম্পিউটার: মজুমদার সাহেব, রহিমা বেগম, ফটিক চাঁদ, কানাই বাবু, নাজমা খালা (আলাদা স্বভাব, সংলাপ); সহজ/মাঝারি/কঠিন

- ৩ডি গড়ানো ছক্কা (ক্লিক করা যায়), শঙ্কু ঘুঁটির ধাপে ধাপে লাফ, বোর্ডের মাঝে কার্ড, ৩ডি বাড়ি/হোটেল, ব্রাউজারে-তৈরি সাউন্ড ও ঘটনার অ্যানিমেশন

## সীমাবদ্ধতা
- একজন কম্পিউটার-চালক দরকার: অনলাইন খেলায় কম্পিউটার চরিত্র ও অটোপাইলট **হোস্টের ব্রাউজার খোলা থাকলে** চলে।
- সাউন্ড ব্রাউজারে তৈরি (প্রথম ক্লিকের পর বাজে)। ভবিষ্যতে আসল অডিও ফাইল `js/sound.js`-এ বসানো যাবে।

## আপডেট নোট
- Firestore rules এ `presence` ও `cheers` যোগ হয়েছে — আবার **Publish** করতে হবে।
- নাম ও অবতার ব্রাউজারে (localStorage) মনে রাখা হয়; Firebase-এর নামহীন পরিচয়ও ওই ব্রাউজারে থাকে। IP ঠিকানা ব্যবহার করা হয় না।
- সময়সীমা: হোস্ট ২০/৩০ মিনিট, নিজের লেখা সময় (৫–৬০০ মিনিট) বা সীমাহীন বাছতে পারেন। সব সম্পত্তি বিক্রি হলে ঘড়ি চালু হয়; সময় শেষে চলতি দান শেষ হয়ে মোট সম্পদে (নগদ + সম্পত্তি + বাড়ি-হোটেল) সেরা জয়ী হন। ঘড়ি একটি নির্দিষ্ট শেষ-সময় ধরে চলে, তাই সব ডিভাইসের ঘড়ি মোটামুটি ঠিক থাকলে সবার পর্দায় প্রায় একই সময় দেখাবে।
- কোটা বাঁচানো: অনলাইন "কে আছে" হার্টবিট প্রতি ৬০ সেকেন্ডে; খেলা শেষ হলে ঘরের সব নথি স্বয়ংক্রিয়ভাবে মুছে যায় (হোস্টের ব্রাউজার ৩ মিনিট পরে, অন্যরা ১ মিনিট পরে নিজেদেরটা)। এর জন্য `firestore.rules` আবার **Publish** করুন (হোস্ট অন্যদের নথি মুছতে পারার নিয়ম যোগ হয়েছে)।
- Firestore দৈনিক সীমা শেষ হলে খেলোয়াড় একটি বন্ধুত্বপূর্ণ বার্তা দেখে ও কম্পিউটারের সাথে খেলার বাটন পায়।

## আপডেট দেওয়ার সময় (চালু গেমের ক্ষতি এড়াতে)
- `index.html`-এর `?v=3` প্রতিবার ফাইল বদলে ডেপ্লয় করার সময় বাড়িয়ে দিন (`?v=6`, `?v=5`…), যাতে সবার ব্রাউজার নতুন কোড নেয়।
- ডেটাবেস (Firestore) আলাদা — সাইট আপলোড করলে চলমান গেমের ডেটা মোছে না।
- গেমের নিয়ম/স্টেটের গঠন বদলালে ব্যস্ত সময়ে ডেপ্লয় করবেন না।


## চ্যাট ও ভয়েস কল (নতুন)
- **নতুন Firestore rules publish করতে হবে** (`firestore.rules` ফাইল আবার কপি করে Firebase Console → Firestore → Rules-এ বসিয়ে Publish)। না করলে চ্যাট/ভয়েস কাজ করবে না।
- চ্যাট: ডানদিক-নিচের "চ্যাট" বাটন। "কাকে" থেকে একাধিক জন বাছলে বার্তা শুধু তারাই দেখবে। খেলা শেষে বার্তা মুছে যায়।
- ভয়েস: বাঁ কলামের "ভয়েস কল" কার্ড → "কলে যোগ দিন" (ব্রাউজার মাইকের অনুমতি চাইবে)। শুধু https সাইটে চলে।
- কিছু মোবাইল নেটওয়ার্কে সরাসরি সংযোগ হয় না। তখন একটি TURN সার্ভার দিতে হয়। বিনামূল্যের TURN-এ (যেমন Metered Open Relay) অ্যাকাউন্ট খুলে `firebase-config.js`-এ যোগ করুন:
  `window.TURN_SERVERS=[{urls:'turn:সার্ভার:80',username:'...',credential:'...'}];`
- ডেপ্লয়ের পর `?v=6` সবার ব্রাউজারে নতুন ফাইল আনবে।


## 🚦 রুম-সীমা, পাবলিক/প্রাইভেট ও দর্শক (v9)

**ছবি বসানো:** `assets/` ফোল্ডারে ৩টি ছবি রাখুন (বিস্তারিত `assets/README.txt`):
`logo-horizontal.png` (1800×600, স্বচ্ছ) · `icon.png` (512×512, স্বচ্ছ) · `app-icon.png` (512×512, সলিড)।
ছবি না থাকলে আগের CSS লোগো ও `favicon.svg` নিজে থেকে দেখানো হয়।

**রুম-স্লট:** একটি অনলাইন খেলা তখনই "চালু" গণ্য হয় যখন হোস্ট *খেলা শুরু* চাপে (লবি/ঘর তৈরি স্লট নেয় না)।
ডিফল্ট: একসাথে **৮টি** চালু খেলা, দিনে (প্যাসিফিক সময়ে) **২০টি**। বদলাতে `firebase-config.js`-এ `window.APP_LIMITS` দেখুন।
সব রুম ভরা থাকলে হোস্ট "অপেক্ষা করি" বেছে নিলে রুম খালি হওয়া মাত্র খেলা নিজে থেকে শুরু হয়। খেলা শেষ হলে বা ১২ মিনিট সাড়া না এলে স্লট ছাড়া হয়।

**দেরিতে যোগ:** সবাই প্রথম চাল না দেওয়া পর্যন্ত দর্শক "যোগ দিতে চাই" চাপতে পারে, হোস্ট "নিন" চাপলে যোগ হয়। সর্বোচ্চ ১০ জন।

**Firestore rules আবার publish করুন** (নতুন `meta/live` নিয়ম যোগ হয়েছে) — না করলে অনলাইন খেলা শুরু হবে না।
